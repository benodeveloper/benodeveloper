## 💫 About Me
I am a **Full-Stack Software Developer** with 7+ years of experience in web and mobile development, system architecture, and cloud deployment. I specialize in building scalable, high-performance applications utilizing **Domain-Driven Design (DDD)** and **Hexagonal Architecture**. 

* 🔭 I’m currently building an **internal regional investment platform** (Laravel, Inertia.js, React) and a **real-time vehicle tracking monolith** (Java Spring Boot).
* 🌱 I’m currently focused on **Test-Driven Development (TDD)** and preparing for my **AWS Certified Developer - Associate (DVA-C02)** exam.
* ⚙️ **Workflow:** All my development is containerized via Docker and done on **Arch Linux** using a heavily customized **Neovim** environment.
* 📫 Reach out at: [listoun.developer@gmail.com](mailto:listoun.developer@gmail.com)
